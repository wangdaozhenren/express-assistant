# 快递助手 · 领域知识模块

> 挂载知识类：① 计价口径 · ② 规格归一 · ⑤ 安全避坑 · ⑥ 平台/渠道知识

## ① 计价口径：总价 = 首重 + 续重（精确到 0.1kg）

- **首重/续重**：常见"首重 1kg X 元，续重 1kg Y 元"，续重不足 1kg 按 1kg 计（部分公司按 0.5kg 计）；总价必须精确计算，不做估算。
- **体积重**：长×宽×高(cm) ÷ 抛比（顺丰 6000、京东 6000/8000、通达系 6000~8000），取"实际重量 vs 体积重"较大者计费。
- **偏远地区附加费**：新疆/西藏/内蒙古等偏远地区加收 10~30 元，报告按收件地核算。
- **时效差价**：次日达 > 隔日达 > 普通件，同公司不同时效价差 3~10 元。
- **活动价**：寄件优惠券（首单立减、满减）依赖账号状态，页面可见才计入并注明。

## ② 规格归一

- **重量档位**：1kg 内 / 1-3kg / 3-10kg / 10kg+ 阶梯价差明显，跨档不直接比；
- **体积档位**：60cm 内 / 60-100cm / 100cm+ 快递公司对大件有不同计费（大件走物流专线更划算）；
- **物品类型**：普通件/文件/生鲜（冷链加价）/电子产品（需保价）分类计费，不同类型不直接比。

## ⑤ 安全避坑

- **低价快递骗局**：异常低价的"代下单"渠道存在丢件不理赔、跑路风险，只比正规平台/快递公司页面价；
- **保价必须如实**：高价值物品不保价丢件仅赔运费数倍，报告提示"贵重物品建议保价"；
- **到付陷阱**：部分公司到付价为现付价 1.5~2 倍，报告标注到付/现付差价；
- **虚假时效承诺**：个别渠道标"次日达"实际 3 天到，报告以快递公司官方承诺时效为准并提示实际体验差异。

## ⑥ 平台/渠道知识

| 渠道 | 特点 | 注意点 |
|---|---|---|
| 顺丰 | 时效最稳、服务最好 | 价格最高；月结客户有折扣 |
| 京东物流 | 自营仓配体验好 | 寄件价格中等偏高 |
| 中通/圆通/韵达 | 通达系性价比 | 时效波动；活动价频繁 |
| 聚推客寄件 | 特价寄快递聚合入口 | 价格有优势，需确认承运商 |
| 菜鸟/聚合寄件 | 多公司比价一站查 | 同一线路多家报价，天然比价入口 |

- 同一线路（同区互寄）不同公司价差可达 50%+，报告按"同线路同时效"原则比较。
